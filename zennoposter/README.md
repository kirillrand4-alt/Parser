# Регистратор аккаунтов (ZennoPoster)

Разовая регистрация **своих** аккаунтов из CSV-файла с автоматическим
подтверждением почты по IMAP.

> Назначение — только легитимное: учётные записи, которые вы имеете право
> заводить, на своих реальных реквизитах. Не для массового создания фейков.

## Файлы

| Файл | Что это |
|------|---------|
| `register_checko.cs` | checko.ru + подтверждение письма (IMAP или веб-Gmail) |
| `prepare_google_profile.cs` | Разовая ПОДГОТОВКА профиля с ручным входом в Gmail |
| `register_b2b.cs` | Универсальный B2B-портал (без email-подтверждения) |
| `accounts.example.csv` | Пример входного файла (разделитель `;`, UTF-8) |
| `proxies.example.txt` | Пример списка прокси (по одной в строке) |

Оба `.cs` — код для кубика **«Свой код» (CodeCreator)** в проекте ZennoPoster.

## Про подтверждение почты (важно)

Письмо-подтверждение читается **по IMAP** (`imap.gmail.com:993`), а не через
веб-вход в Gmail. Автоматический вход в веб-Gmail Google целенаправленно
блокирует (капча, проверки «это вы?»), поэтому он здесь не используется.

Что нужно один раз настроить в Google-аккаунте:

1. Включить двухфакторную аутентификацию (2FA).
2. `Аккаунт Google → Безопасность → Пароли приложений → создать`.
3. Полученные 16 символов вписать в CSV-колонку `email_app_password`
   (или в константу `imapAppPasswordDef` в коде, если аккаунт один).

Обычный пароль от почты для IMAP при включённой 2FA не подойдёт — нужен именно
пароль приложения.

## Два способа прочитать письмо-подтверждение

Переключатель `emailReadMode` в `register_checko.cs`:

- **`imap`** (по умолчанию, рекомендуется) — читает письмо по IMAP с паролём
  приложения. Не требует входа в браузерный Gmail, работает стабильно.
- **`gmail_web`** — открывает Gmail в браузере в **заранее авторизованном
  профиле** и читает письмо оттуда. Годится, если не хочешь заводить пароль
  приложения. Вёрстка Gmail ломкая — при изменениях правь `xpGmailFirstMail`.

### Подготовка профиля для gmail_web (или входа через Google на checko)

Google-вход **выполняется вручную** — автоввода пароля и обхода проверок Google
здесь нет (это блокируется и запрещается). Делается один раз на аккаунт:

1. Вставь `prepare_google_profile.cs` в кубик «Свой код», задай `profilePath`.
2. Запусти в ProjectMaker — откроется браузер. **Войди в Gmail руками**
   (логин, пароль, 2FA, капча — всё сам).
3. Скрипт поймает факт входа и сохранит профиль (куки-сессию) в `profilePath`.
4. Путь к этому профилю впиши в CSV-колонку `profile` для нужного аккаунта.

Дальше `register_checko.cs` загрузит профиль сам — Gmail уже авторизован.

## Быстрый старт (checko.ru)

1. **Данные.** Скопируйте `accounts.example.csv` → `accounts.csv`, впишите свои
   `email;password;email_app_password`.

2. **Проект.** ZennoPoster → новый проект → кубик **«Свой код»** → вставьте
   содержимое `register_checko.cs`.

3. **Настройка (блок SETTINGS вверху кода):**
   - `csvPath`, `resultPath` — пути к файлам.
   - `regUrl` — страница регистрации.
   - `xpEmail`, `xpPassword`, `xpSubmit` и пр. — XPath полей формы
     (ПКМ по полю → «Показать в HTML» → скопировать XPath). Ненужные поля —
     пустая строка `""`, они пропускаются.
   - `mailFromFilter` — отправитель письма (`checko`), `confirmLinkRegex` —
     шаблон ссылки подтверждения (подправьте, если ссылка другого вида).
   - `mailWaitSeconds` / `mailPollSeconds` — сколько ждать письмо и как часто
     опрашивать ящик.

4. **Запуск.** Один прогон проходит по всем строкам CSV: регистрирует, ждёт
   письмо, переходит по ссылке подтверждения, пишет статус в
   `accounts_result.csv` (`OK` / `PARTIAL` / `FAIL` / `ERROR`).

## Прокси

Скопируйте `proxies.example.txt` → `proxies.txt`, по одной прокси в строке
(`ip:port`, `login:pass@ip:port`, `socks5://...`). В коде:

- `proxyListPath` — путь к файлу; пустая строка `""` = без прокси.
- `proxyRequired = true` — если живой прокси нет, аккаунт пропускается
  (`SKIP`); `false` — тогда при отсутствии прокси работаем напрямую.
- `proxyMaxTry` — сколько прокси перебрать, если очередная не отвечает.

Прокси выдаются **по кругу, по одной на аккаунт**, с проверкой живости
(запрос своего IP через `api.ipify.org`). Нерабочие пропускаются автоматически.

> IMAP-подключение к почте идёт **напрямую**, не через прокси — так надёжнее и
> Gmail не ругается на смену IP при заходе в ящик.

## Заметки

- `confirmLinkRegex` по умолчанию ловит ссылки вида
  `https://checko.ru/...confirm|activ|verif|token|key...`. Пришлите реальный
  вид письма — подгоню шаблон точно.
- IMAP-клиент минимальный (без внешних DLL): берёт самое свежее письмо от
  `mailFromFilter`, декодирует quoted-printable и вытаскивает ссылку.
- Капчу скрипт не обходит. Если на форме checko есть капча — её надо решать
  отдельным сервисом-распознавателем (штатный кубик ZennoPoster).
- XPath'ы под форму checko.ru проставьте свои — пришлите HTML формы, и я задам
  их точно.

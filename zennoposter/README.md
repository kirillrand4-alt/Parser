# ZennoPoster — шаблон «Генератор правдоподобного профиля» (ProjectMaker 7.7.2)

Шаблон из кубиков, который:

1. Берёт прокси из файла и **удаляет использованную строку** (потокобезопасно).
2. Генерирует **максимально правдоподобный профиль** пользователя: User-Agent,
   платформа/ОС, набор шрифтов, WebGL vendor/renderer, Canvas-шум, разрешение
   экрана, языки, часовой пояс, WebRTC, геолокацию.
3. Согласует часовой пояс / язык / геолокацию **с гео прокси** — это ключ к
   правдоподобности (без рассинхрона «IP в США — таймзона Москвы»).
4. Стартует браузер и (опционально) проверяет отпечаток на browserleaks/whoer.
5. Сохраняет профиль (cookies + fingerprint) в файл, чтобы переиспользовать.

> В ZennoPoster 7.7.2 браузер — на движке **Chromium** с полноценной эмуляцией
> отпечатка. Самый правдоподобный отпечаток даёт **штатный генератор профиля**
> (кубик «Профиль → Взять случайный профиль»), потому что он берёт связки
> UA + WebGL + шрифты + экран из реальной базы устройств ZennoLab, где все поля
> согласованы между собой. Ручная генерация UA «по кусочкам» почти всегда даёт
> нестыковки, которые ловят антифроды. Поэтому шаблон построен вокруг штатного
> генератора, а C#-код используется только для оркестрации (прокси, файлы, гео).

## Файлы

```
zennoposter/
├── README.md                       ← этот файл (сборка из кубиков)
├── data/
│   ├── proxies.txt                 ← ваши прокси (по строке на прокси)
│   └── profiles/                   ← сюда сохраняются готовые профили
└── code_cubes/
    ├── 01_proxy_from_file.cs       ← C# кубик: взять прокси и удалить строку
    ├── 02_set_proxy.cs             ← C# кубик: применить прокси к инстансу
    ├── 03_geo_from_proxy.cs        ← C# кубик: подтянуть гео/таймзону под прокси
    ├── 04_save_profile.cs          ← C# кубик: сохранить профиль в файл
    └── 05_save_api_key.cs          ← C# кубик: снять API-ключ с checko.ru и сохранить
```

## Формат файла с прокси (`data/proxies.txt`)

Одна прокси на строку. Поддерживаются форматы (код сам разберёт):

```
ip:port
ip:port:login:password
login:password@ip:port
socks5://login:password@ip:port
http://ip:port
```

Схема (`http://` / `socks5://`) необязательна — по умолчанию `http`.

## Сборка шаблона из кубиков (пошагово)

Открой **ProjectMaker 7.7.2** → создай новый проект → перетаскивай кубики
из левой панели в указанном порядке. Настройки каждого кубика ниже.

### 1. Кубик «Обработка файла → Взять строку» (native, без кода)

Самый надёжный и потокобезопасный способ «взять прокси и удалить строку» —
это **штатный** кубик, а не C#. Настройки:

- **Действие:** `Взять из файла` (Get line from file)
- **Файл:** `{-Project.Directory-}\data\proxies.txt`
- **Как брать строку:** `Первую` (First line)
- ✅ **Удалять взятую строку** (Delete line after taking) — включить
- **Результат в переменную:** `proxyRaw`

> Штатный кубик сам ставит блокировку файла между потоками — при работе в
> много-поточном режиме строки не задвоятся и не потеряются.
>
> Альтернатива на C# (если нужен разбор форматов/лог) — `code_cubes/01_proxy_from_file.cs`.
> Он тоже потокобезопасный (через `Mutex`) и кладёт разобранную прокси в
> переменные `proxy`, `proxyIp`, `proxyPort`.

### 2. Кубик «Ветвление (If)» — есть ли прокси

- Условие: переменная `proxyRaw` **не пустая**.
- Если пусто → ветка в кубик **«Ошибка / Стоп поток»** с текстом
  «Прокси закончились» (чтобы шаблон не работал без прокси с реального IP).

### 3. Кубик «Профиль → Взять случайный профиль» (штатный генератор отпечатка)

Это и есть «максимально правдоподобный профиль».

- **Действие:** `Сгенерировать / Взять случайный` (Random profile)
- **Настройки генерации** (кнопка ⚙ в кубике):
  - **Уровень эмуляции браузера:** `Высокий (High)` — включает подмену
    WebGL, Canvas, AudioContext, шрифтов, экрана, платформы.
  - **ОС / браузер:** оставь `Любой` или ограничь под задачу
    (напр. только `Windows` + `Chrome` — самая массовая связка).
  - **Разрешение экрана:** `Из базы устройств` (не «случайное число» —
    берём реальные разрешения).
  - **Шрифты:** `Согласованные с ОС` (набор шрифтов должен совпадать
    с заявленной платформой — Windows-шрифты для Windows-UA).
  - **Языки (Accept-Language):** временно `en-US` — на шаге 4 перепишем под гео прокси.
- **Применить к инстансу:** ✅ (Apply to instance)

> Именно связка из базы ZennoLab даёт согласованные UA ↔ platform ↔ WebGL ↔
> шрифты ↔ экран. Не редактируй эти поля вручную по одному — сломаешь
> согласованность отпечатка.

### 4. Кубик «C# код → Гео под прокси» → `code_cubes/03_geo_from_proxy.cs`

Подтягивает страну/таймзону/язык под IP прокси и пишет их в переменные
`geoTimezone`, `geoLang`, `geoCountry`. Это убирает главный признак бота —
рассинхрон «IP страны X, а таймзона/язык страны Y».

### 5. Кубик «Профиль → Настройки → Таймзона / Язык / WebRTC»

- **Часовой пояс:** из переменной `{-Variable.geoTimezone-}`
- **Accept-Language / navigator.language:** `{-Variable.geoLang-}`
- **WebRTC:** режим `Подменять по прокси` (Altered / Replace with proxy) —
  чтобы реальный IP не утёк через WebRTC.
- **Геолокация:** `Разрешить + координаты по IP` (или `Запросить у пользователя`).

### 6. Кубик «C# код → Применить прокси» → `code_cubes/02_set_proxy.cs`

Ставит прокси на инстанс из переменной `proxy`
(`instance.SetProxy(...)`), с указанием схемы (http/socks5).

### 7. Кубик «Браузер → Старт / Перейти на URL»

- Стартуй браузер (если ещё не стартовал) и открой проверочную страницу,
  напр. `https://browserleaks.com/canvas` или `https://whoer.net`.
- Это опционально — для визуальной проверки отпечатка при отладке.

### 8. Кубик «C# код → Сохранить профиль» → `code_cubes/04_save_profile.cs`

Сохраняет cookies + fingerprint профиля в
`data\profiles\<uid>.zpprofile`, чтобы в следующий раз **загрузить готовый
профиль** (кубик «Профиль → Загрузить из файла»), а не генерировать заново —
переиспользование профиля выглядит естественнее, чем новый профиль каждый раз.

### 9. Снять и сохранить API-ключ с checko.ru

Когда аккаунт checko.ru уже залогинен в текущем профиле:

1. Кубик **«Браузер → Перейти по URL»** → `https://checko.ru/user/account/api`.
2. Достаём данные из блока **«Ваш API-ключ»** — двумя способами:

   **Вариант A (штатные кубики, без кода):**
   - Кубик **«Получить элемент / Get element»**: селектор CSS `div.code`,
     атрибут `innertext` → переменная `apiKey`.
   - (опц.) ещё раз для тарифа: CSS `div.h2.mt-0` → переменная `tariff`.
   - Кубик **«Добавить строку в файл»** (thread-safe): файл
     `{-Project.Directory-}\data\api_keys.txt`, текст
     `{-Variable.apiEmail-} | {-Variable.apiKey-} | {-Variable.tariff-} | {-Variable.proxyIp-}:{-Variable.proxyPort-}`.

   **Вариант B (один C# кубик):** `code_cubes/05_save_api_key.cs` — сам парсит
   ключ + тариф + e-mail регэкспом из HTML страницы и потокобезопасно дописывает
   строку в `data/api_keys.txt`. Кладёт в переменные `apiKey`, `tariff`, `apiEmail`.

> Ключ на странице лежит в `<div class="code">jBGhUK88hv5PS6gK</div>`, тариф —
> в `<div class="h2 mt-0">«Лайт»</div>`. Кубик 05 привязывает ключ к IP прокси,
> под которым он был получен, — удобно для дальнейшего использования ключа
> через тот же прокси.

## Порядок кубиков (схема потока)

```
[1 Взять строку из proxies.txt (+удалить)]  →  proxyRaw
        │
[2 If proxyRaw пустая?] ── да ──► [Стоп: прокси закончились]
        │ нет
[3 Профиль: случайный, эмуляция High, применить]
        │
[4 C#: гео/таймзона/язык под прокси]  →  geoTimezone, geoLang
        │
[5 Профиль: таймзона+язык+WebRTC под прокси]
        │
[6 C#: SetProxy(proxy)]
        │
[7 Браузер: старт + (опц.) страница проверки]
        │
[8 C#: сохранить профиль в файл]
```

## Готовый профиль на выходе включает

| Параметр | Источник | Согласовано с |
|---|---|---|
| User-Agent | база устройств ZennoLab | platform, WebGL, шрифты |
| navigator.platform / OS | база устройств | UA |
| Шрифты | набор ОС | платформа |
| WebGL vendor / renderer | база GPU | ОС/устройство |
| Canvas / AudioContext | шум профиля | стабилен внутри профиля |
| Разрешение / глубина цвета | реальные значения | устройство |
| Часовой пояс | по IP прокси | страна прокси |
| Язык (Accept-Language) | по IP прокси | страна прокси |
| WebRTC | подмена по прокси | IP прокси (нет утечки) |
| Геолокация | по IP | страна прокси |
| Cookies | накапливаются в профиле | сохраняются в файл |

## Быстрый старт

1. Положи прокси в `data/proxies.txt` (по одной на строку).
2. Собери кубики по инструкции выше (или вставь `.cs` в кубики «Свой код C#»).
3. Запусти в ProjectMaker в много-поточном режиме — каждый поток заберёт
   свою прокси, сгенерит свой профиль и сохранит его.

> Примечание: строки с `#` пропускает только C#-кубик 01. Штатный кубик
> «Взять строку» комментарии не понимает — для него держите в `proxies.txt`
> только чистые прокси, без строк с `#`.

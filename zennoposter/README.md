# Регистратор аккаунтов (ZennoPoster)

Разовая регистрация **своих** аккаунтов на B2B-портале поставщика из CSV-файла.
Скрипт заполняет форму регистрации по каждой строке и пишет отчёт.

> Назначение — только легитимное: учётные записи, которые вы имеете право
> заводить, на своих реальных реквизитах. Не для массового создания фейков.

## Файлы

| Файл | Что это |
|------|---------|
| `register_b2b.cs` | Код для кубика **«Свой код» (CodeCreator)** в проекте ZennoPoster |
| `accounts.example.csv` | Пример входного файла с данными (разделитель `;`, кодировка UTF-8) |

## Быстрый старт

1. **Данные.** Скопируйте `accounts.example.csv` в `accounts.csv` и впишите свои
   реквизиты. Первая строка — заголовок, менять названия колонок не нужно:
   `company;inn;contact;email;phone;password`.

2. **Проект.** В ZennoPoster создайте проект → добавьте кубик **«Свой код»** →
   вставьте содержимое `register_b2b.cs`.

3. **Настройка (блок SETTINGS вверху кода):**
   - `csvPath`, `resultPath` — пути к входному файлу и отчёту.
   - `regUrl` — адрес страницы регистрации портала.
   - `xp*` — XPath-селекторы полей формы. Подсмотреть просто:
     запустите проект в режиме записи, откройте форму, **ПКМ по полю →
     «Показать в HTML»**, скопируйте XPath. Поля, которых нет на портале,
     оставьте пустой строкой `""` — скрипт их пропустит.
   - `xpSuccessMark` / `successText` — как определить, что регистрация прошла
     (блок «Спасибо» или текст на странице).

4. **Запуск.** Один прогон проходит по всем строкам CSV. По каждой пишется
   строка в `accounts_result.csv` со статусом `OK` / `FAIL` / `ERROR`.

## Заметки

- `typingEmulation = true` — посимвольный ввод (естественнее). `false` — вставка
  значения целиком (быстрее).
- Паузы между действиями рандомизированы (`minDelayMs`…`maxDelayMs`).
- Капчу/подтверждение по SMS/email скрипт не обходит. Если на портале есть
  подтверждение почты — заведите отдельный шаг чтения письма (кубик работы с
  POP3/IMAP в ZennoPoster) уже после регистрации.
- Прокси/профили не используются: для единичной регистрации своих учёток это не
  нужно. Если портал сам просит — настраивается штатными средствами проекта.
